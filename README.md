# Typing Game

## 概要
2Dタイピングゲームです。単体のアルファベットを打つ練習モードや、単語を制限時間内に打つタイムアタックモードがあり、
これからタイピング練習をしたいと思っている人向けに制作しました。

## 制作情報
- 制作期間: 2026年1月～2026年4月
- 開発人数: 1人
- 担当範囲: 企画、実装、デバッグ、UI作成

## 使用技術
- C++
- DxLib
- Visual Studio
- Git

## 工夫した点
-  タイトル、ゲーム、リザルト画面などをSceneクラスで共通化し、GameManagerですべてのシーンの移行を管理するようにした。
